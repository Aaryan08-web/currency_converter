## ✨ Features

- 🌍 **162+ supported currencies**
- 💱 Fast currency conversion
- 🔄 One-click currency swap
- 🚩 Dynamic currency flags
- 📊 Displays converted amount and exchange rate
- 🕒 Shows latest available rate update
- ⚡ 24-hour local rate caching
- 🛡️ Input validation
- ⏳ Loading state during API requests
- ⚠️ Network and API error handling
- ⌨️ Enter-to-convert support
- 📱 Fully responsive design
- 🔢 Professional number formatting
- 🔐 No private API key exposed in frontend
